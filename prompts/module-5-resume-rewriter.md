# Module 5: Resume Positioning Rewriter (简历定位重写工具)

## Prompt

```
为我重写简历的职业概述和经验要点，以适配以下目标角色：

[TARGET ROLE / JOB TITLE]

要求：
- 强调与该角色最相关的成就、可转移技能和可衡量的成果
- 使用该行业/角色的标准术语和关键词（便于ATS筛选）
- 每条经历点用「动词 + 事项 + 量化结果」格式
- 职业概述控制在150字以内
- 绝对不捏造资历或编造不存在的经历

重写完成后，对每个修改点给出说明：
1. 改了什么（原文 → 改后）
2. 为什么改（与目标角色的关联）
```

## Output Format

```markdown
## 重写后的简历

### 职业概述
[150字以内]

### 工作/项目经历
[重写后的内容]

---

## 修改说明

### 职业概述改动
- 原文：...
- 改后：...
- 原因：...

### 经历点改动
#### [经历标题]
- 原文第X条：...
- 改后：...
- 原因：...
```

## Rules

1. **不编造**：只改表述方式和侧重点，事实不变
2. **量化保守**：只用简历原有数字；无数字的用描述性表述（"多次"、"主导"等）
3. **关键词匹配**：从JD中提取高频词，自然融入改写后的文本
4. **STAR法则**：每条经历尽量体现 Situation → Task → Action → Result
5. **篇幅控制**：改后简历控制在1-2页（中文）/ 1页（英文）

## Notes

- 如果简历有多个版本（中/英文），分别重写
- 针对用户背景：华东理工大学硕士在读，目标硬件产品经理校招
- ATS优化：确保改写后的文本包含JD中的关键术语
