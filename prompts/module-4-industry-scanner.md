# Module 4: Best-Fit Industry Scanner (最佳匹配行业扫描器)

## Prompt

```
分析我的简历经验，识别10个我的技能可能有价值的行业。

对每个行业，请按以下维度评分和分类：

1. 招聘需求（热 / 稳 / 冷）— 该行业当前招聘活跃度
2. 薪酬水平（给出范围）— 该行业对标岗位的市场薪资
3. 远程工作潜力（高 / 中 / 低）— 该行业远程/混合办公的可能性
4. 职业成长空间（★~★★★★★）— 未来3-5年晋升和薪资增长潜力
5. 进入难度（易 / 中 / 难）— 是否需要从零开始，还是可以直接迁移

最后对每个行业用一句话说明：为什么我的技能组合在这个行业有价值。

总结：哪些行业是"低投入高回报"的最优选择（容易进入 + 成长好）。
```

## Output Format

```markdown
| # | 行业 | 招聘 | 薪资 | 远程 | 成长 | 难度 | 适配理由 |
|---|------|------|------|------|------|------|---------|

### 最优选择（低投入高回报）
1. ...
2. ...
```

## Notes

- 行业分类用中国市场的标准分类（如：智能制造、消费电子、新能源汽车、医疗器械等）
- 薪资范围标注国内一线/新一线城市的市场价
- 远程潜力在国内语境下解释（是否支持弹性办公/出差频率等）
