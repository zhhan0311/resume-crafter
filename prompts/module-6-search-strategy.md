# Module 6: Job Search Strategist (机会搜索策略)

## Prompt

```
基于我的简历和目标职位，创建一个为期30天的系统化求职搜索计划。

请包含以下内容：

1. **目标职位标题清单**（8-10个，从最匹配到最广）
2. **搜索关键词**（中文 + 英文，覆盖主流招聘平台）
3. **推荐企业类型和具体公司名**（至少15家，按优先级排序）
4. **每周申请目标**
   - 第1周：准备期（简历终版、作品集、搜索账号）
   - 第2周：密集投递期
   - 第3周：网络拓展 + 补充投递
   - 第4周：跟进 + 面试准备
5. **网络拓展行动**
   - 目标社群/论坛/LinkedIn群组
   - 值得关注的行业KOL
   - 内部推荐策略
6. **招聘人员联系模板**（3个版本：LinkedIn私信 / 邮件 / 微信）
7. **每周绩效检查点**
   - 申请数量目标
   - 回复率目标
   - 面试转化目标
   - 需要调整的信号
```

## Output Format

```markdown
## 30天求职计划

### 目标职位 & 关键词
...

### 企业名单
| 优先级 | 公司 | 类型 | 投递渠道 | 备注 |
|--------|------|------|---------|------|

### 周计划
#### Week 1: 准备期
- [ ] ...
#### Week 2: 密集投递
- [ ] ...
#### Week 3: 网络拓展
- [ ] ...
#### Week 4: 跟进收尾
- [ ] ...

### 联系模板
...

### 检查点
| 周 | 申请数 | 回复率 | 面试数 | 行动项 |
|----|--------|--------|--------|--------|
```

## Notes

- 企业名单优先考虑用户所在城市/区域的公司
- 搜索关键词要适配国内主流平台（Boss直聘、牛客、智联、猎聘等）
- 联系模板语气专业但不生硬，中文为主
