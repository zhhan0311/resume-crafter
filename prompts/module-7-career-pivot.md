# Module 7: Career Pivot Map (职业支点地图)

## Prompt

```
使用我的简历创建5条现实的职业支点路线。

对每条路线，请提供：

1. **初始角色**（现在就能申请的，不需要额外资质的入门岗位）
2. **可转移经验**（简历中哪些经历直接适用，逐条引用）
3. **缺失技能**（转到这个方向还差什么）
4. **推荐项目**（做什么具体项目/作品能快速补上缺失技能）
5. **薪资范围**（初始角色的市场薪资 + 3年后预期）
6. **30天过渡计划**（下个月具体每天/每周做什么）

要求：
- 5条路线要有差异性，覆盖不同方向（不要5个类似岗位）
- 每条路线必须是"从我当前位置出发能走通的"，不要幻想
- 初始角色必须是我明天就能投递的，不需要先读个学位或考证
- 30天计划要具体到行动级别（"写一篇XX领域的分析文章"而不是"学习XX"）
```

## Output Format

```markdown
## 职业支点地图

### 路线1：[方向名称]
**初始角色**：...
**可转移经验**：
- [简历原文引用]
**缺失技能**：...
**推荐项目**：...
**薪资**：初始 XX万 → 3年后 XX万
**30天计划**：
| 周 | 行动 | 产出 |
|----|------|------|

---

### 路线2：[方向名称]
...

---

## 你觉得哪条路线最吸引你？
[引导用户选择，追问细节]
```

## Notes

- 路线排序：最匹配的排第一，最大胆的排最后
- 如果用户有明确偏好（如"不想出差"、"想做管理"），据此调整路线
- 结尾必须有追问，引导用户深入讨论感兴趣的路线
- 针对用户背景：华理硕士在读 + 聚光科技实习 + 专利 + 机器人实验室 → 路线要利用这些素材
