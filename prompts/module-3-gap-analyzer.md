# Module 3: Qualification Gap Analyzer (资格差距分析器)

## Prompt

```
将我的简历与以下目标职位进行逐条对比：

[PASTE JOB DESCRIPTION HERE]

请分析：

1. ✅ 已满足：直接匹配的硬性要求，逐条列出简历中对应的证据
2. ⚠️ 部分满足：有相关经验但需要强化表述或补充说明的条目
3. ❌ 缺失：简历中完全未覆盖的要求
4. 🔧 弥补建议：对每条❌缺失项给出：
   - 最快补法（具体行动，不是"学习XX"这种空话）
   - 预估时间（天/周）
   - 是否可以通过项目/作品集快速证明

最后给出综合匹配度评分（百分比），以及一条"如果只做一件事来提升匹配度，应该做什么"。
```

## Output Format

```markdown
### ✅ 已满足 (X/Y条)
- [JD要求] → [简历证据]

### ⚠️ 部分满足 (X/Y条)
- [JD要求] → [简历中相关但不完全匹配的部分] → 建议如何强化

### ❌ 缺失 (X/Y条)
- [JD要求]
  - 🔧 补法：...
  - ⏱ 时间：...
  - 📦 项目证明：...

### 综合匹配度：XX%

### 最优先改进项
如果只做一件事：...
```

## Notes

- 逐条比对，不要笼统概括
- 匹配度评分要诚实，不要虚高
- 弥补建议要具体可执行，不要泛泛而谈
- 如果JD中有"优先"/"加分"项，单独标注，不要混入硬性要求
