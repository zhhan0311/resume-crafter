# Module 2: Transferable Skills Translator (可转移技能翻译器)

## Prompt

```
审阅我的简历并提取每项雇主可能重视的可转移技能（目标：20-30项）。

对每项技能，请提供：
1. 技能名称
2. 适配行业（哪些行业需要这个能力）
3. 适配部门（哪个部门/团队用得上）
4. 适配职位（具体岗位名称）
5. 经验证据（从简历原文引用，证明我确实有这个能力）

最后将所有技能按类别分组：
- 技术类（Hard Skills）
- 软技能（Soft Skills）
- 管理类（Management）
- 领域知识（Domain Knowledge）

每个类别下标注：哪些技能是最强卖点，哪些需要进一步证明。
```

## Output Format

```markdown
### 技术类
| 技能 | 适配行业 | 适配部门 | 适配职位 | 经验证据 |
|------|---------|---------|---------|---------|
| ...  | ...     | ...     | ...     | 简历原文 |

### 软技能
...

### 管理类
...

### 领域知识
...
```

## Notes

- "经验证据"必须直接引用简历原文，不可编造
- 如果简历某项经历可以拆出多个技能，分别列出
- 优先列出与用户目标方向最相关的技能
